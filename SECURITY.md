# Security Policy

## Reporting a Vulnerability

Please do not report security-sensitive issues in public GitHub issues.

Instead, contact the maintainers through a private channel if one is available
for this repository. If no private contact is currently documented, open a
GitHub issue only for non-sensitive problems and add a maintainer contact route
as part of the follow-up work.

## Response Expectations

- Acknowledge receipt of a report as soon as practical.
- Work with the reporter to understand impact and reproduction steps.
- Prepare a fix and coordinate disclosure when the issue is confirmed.
